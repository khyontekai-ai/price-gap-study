# v0.1.0 research reproducibility package

Prepared 29 October 2026. This is a packaging version, not a new scientific run.

- Self-contained daily/monthly loaders replace a neighbouring-checkout import.
- MIT licence for original software, author citation metadata and explicit scope
  exclusions for the manuscript and third-party data.
- Audited 14-page manuscript, 59 references and 18 tables; numerical results and
  scientific method code unchanged during packaging.
- Pinned local package inventory, raw snapshot checksums and provenance gaps.
- No-training verification of the main table, matched controls and corrected
  calendar inference from a separate saved-prediction bundle.
- Upload scripts with dry-run/private defaults, integrity checks and explicit
  public/data-rights confirmations. No credentials or raw prices in the code repo.

Public empirical replication still depends on lawful access to the matching
artifacts/raw snapshots. Full external downstream refitting is not included.
No new untouched evaluation, prospective test or model retraining is claimed.
